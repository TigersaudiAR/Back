# منصة مصحف الهدى التعليمية

هذا المستودع يحتوي على تطبيق متكامل بواجهتين (الواجهة الأمامية والخلفية) لتجربة تعليمية متخصصة بالقرآن الكريم والأذكار وحلقات التحفيظ.

## المتطلبات المسبقة
- Node.js 18+
- npm

## بنية المشروع
```
Back/
  front/   # تطبيق React + Vite + Tailwind + DaisyUI
  back/    # خادم Express TypeScript
```

## تشغيل الواجهة الأمامية
```bash
cd front
npm install
npm run dev
```

## تشغيل الخادم الخلفي
```bash
cd back
npm install
npm run dev
```

سيتوفر الخادم على العنوان `http://localhost:4000` وستستهلكه الواجهة عبر المسار `/api`.

## البناء للإنتاج
```bash
cd front && npm run build
cd ../back && npm run build
```

## المزايا الرئيسية
- عرض القرآن الكريم بوضع حديث ملء الشاشة وشريط أدوات مخفي.
- مسبحة ذكية تدعم العد الصوتي والنقر والإيقاع مع تحديد الأذكار حسب الوقت.
- وحدات تعليمية ذاتية لتعلم العربية والتجويد والحفظ مع نظام أوسمة.
- إدارة حلقات التحفيظ مع لوحة صدارة لأفضل 100 مشارك.
- قسم الأحاديث النبوية من مصادر معتمدة مع إمكانية البحث.
- قسم الدعوة والإرشاد للإجابة عن أسئلة الزوار.
- قناة تواصل فورية مع أهل العلم وتخزين الأسئلة المرسلة.
- لوحة تحكم للأدوار المختلفة لإدارة المحتوى والمستخدمين.
